# Live2D Viewer

An online viewer for Live2D models with motion playback, parameter control, and recording capabilities.

## Features
- Import and display Live2D models
- Play motions and expressions
- Adjust parameters in real-time
- Enable/disable model parts
- Merge multiple motions
- Record videos with optional audio
- Take snapshots
- Customizable backgrounds

## Usage
1. Click the folder icon to import your Live2D model
2. Use the control bar to access motions, parameters, and other features
3. Keyboard shortcuts: M (motions), P (parameters), E (expressions), R (recording), etc.

## Notes
- Models are loaded locally in your browser
- No data is uploaded or stored on any server
- Built with Live2D Cubism SDK
